下面这份可以直接交给 Antigravity。第二优先级的目标不是把两路改成完全对称的混合，而是在保持当前稳定残差结构的基础上，将固定权重

[
Z_j=E_j+\lambda I_j
]

改成：

[
\boxed{
Z_j=E_j+\beta_j I_j
}
]

其中 (\beta_j) 由显式高斯场派生的局部几何状态决定。

当前 `delta` 和 `confidence` 已经从显式高斯场计算出来，但只用于 Jet 内部；整个 `res_proj` 仍通过固定 `gs_residual_weight` 注入。 此外，`res_proj` 同时包含原始观测线性投影和 Gaussian Jet，因此第二修复应控制整个 observation-level pathway，而不是只给 Jet 再乘一次系数。

------

# 一、第二优先级的设计目标

完成后架构应为：

[
E_j=\text{ExplicitGaussianField}_j,
]

[
I_j=
W_{\mathrm{base}}P_jx+
\eta C_jW_G(q_j^{(0)}+\Delta_jq_j^{(1)}),
]

[
\beta_j=
\beta_{\max}
\sigma\left(
b_0+
G\left(
1-C_j,,
\frac{|\Delta_j|}{\Delta_{\max}}
\right)
\right),
]

[
Z_j=E_j+\beta_jI_j.
]

这里：

- (1-C_j)：显式高斯场的局部覆盖不确定性；
- (|\Delta_j|/\Delta_{\max})：归一化局部迁移幅度；
- (\beta_j)：应该注入多少原始观测级证据；
- (\beta_{\max})：防止隐式通路压过显式场。

核心逻辑是：

> 高斯场覆盖充分且局部结构稳定时，以显式场为主要结构锚点；覆盖不足或局部迁移明显时，增强 observation-level pathway 的注入。

# 三、新增 `geometry_fusion.py`

建议创建：

```python
import math

import torch
import torch.nn as nn


class GeometryConditionedResidualGate(nn.Module):
    """
    Produce a sample- and patch-dependent residual injection weight from
    field-derived geometric statistics.

    Inputs
    ------
    confidence:
        Explicit-field coverage confidence, shape (N, P, 1).
    delta:
        Local normalized displacement, shape (N, P, 1).
    max_shift_local:
        Maximum absolute local displacement allowed by the Jet.

    Output
    ------
    beta:
        Residual injection weight, shape (N, P, 1), bounded in
        (0, beta_max).
    features:
        The normalized geometric features used by the gate.
    """

    def __init__(
        self,
        hidden_dim: int = 16,
        beta_init: float = 0.1,
        beta_max: float = 0.5,
    ):
        super().__init__()

        if hidden_dim <= 0:
            raise ValueError(
                f"hidden_dim must be positive, got {hidden_dim}"
            )

        if beta_max <= 0.0:
            raise ValueError(
                f"beta_max must be positive, got {beta_max}"
            )

        if not 0.0 < beta_init < beta_max:
            raise ValueError(
                "beta_init must satisfy 0 < beta_init < beta_max, "
                f"got beta_init={beta_init}, beta_max={beta_max}"
            )

        self.beta_max = float(beta_max)

        init_ratio = beta_init / beta_max
        base_logit = math.log(
            init_ratio / (1.0 - init_ratio)
        )

        self.register_buffer(
            "base_logit",
            torch.tensor(base_logit, dtype=torch.float32),
            persistent=False,
        )

        self.gate_mlp = nn.Sequential(
            nn.Linear(2, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, 1),
        )

        # Make the initial gate exactly equal to beta_init for all
        # samples and patches.
        nn.init.zeros_(self.gate_mlp[-1].weight)
        nn.init.zeros_(self.gate_mlp[-1].bias)

    def forward(
        self,
        confidence: torch.Tensor,
        delta: torch.Tensor,
        max_shift_local: float,
    ):
        if confidence.ndim != 3 or confidence.shape[-1] != 1:
            raise ValueError(
                "confidence must have shape (N, P, 1), "
                f"got {tuple(confidence.shape)}"
            )

        if delta.shape != confidence.shape:
            raise ValueError(
                "delta and confidence must have the same shape, "
                f"got delta={tuple(delta.shape)}, "
                f"confidence={tuple(confidence.shape)}"
            )

        if max_shift_local <= 0.0:
            raise ValueError(
                "max_shift_local must be positive, "
                f"got {max_shift_local}"
            )

        eps = 1e-6

        # Larger uncertainty means the explicit field provides weaker
        # local support, so more observation-level evidence may be useful.
        uncertainty = (
            1.0 - confidence
        ).clamp(0.0, 1.0)

        # Normalize displacement to a bounded and configuration-independent
        # quantity.
        shift_magnitude = (
            delta.abs() / (max_shift_local + eps)
        ).clamp(0.0, 1.0)

        geometry_features = torch.cat(
            [
                uncertainty,
                shift_magnitude,
            ],
            dim=-1,
        )

        gate_offset = self.gate_mlp(
            geometry_features
        )

        base_logit = self.base_logit.to(
            device=gate_offset.device,
            dtype=gate_offset.dtype,
        )

        beta = self.beta_max * torch.sigmoid(
            base_logit + gate_offset
        )

        return beta, geometry_features
```

# 四、为什么 gate 输入使用这两个量

建议第一版只使用：

[
\boxed{
1-\mathrm{confidence},
\qquad
|\Delta|/\Delta_{\max}
}
]

不要一开始加入：

- `rendered_event`；
- `res_proj`；
- (d_{\text{model}}) 维特征；
- 显式和隐式特征拼接；
- attention；
- channel embedding。

原因有三个。

## 1. 与论文故事严格一致

这是一个真正的：

> geometry-conditioned coupling

而不是普通 feature fusion MLP。

## 2. 输入已经归一化

两个输入都在 ([0,1]) 中：

[
1-C_j\in[0,1],
\qquad
|\Delta_j|/\Delta_{\max}\in[0,1].
]

这样不同数据集、不同 `patch_len` 和不同 `jet_max_shift_samples` 下更稳定。

## 3. 参数和计算量极小

两层小 MLP 的参数量约为：

[
2H+H+H+1\approx4H+1.
]

当 (H=16) 时只有几十个参数，基本不会影响训练速度。

# 五、为什么必须零初始化最后一层

当前固定融合为：

[
Z=E+0.1I.
]

第二修复刚加入时，不应立刻改变模型初始函数，否则无法判断性能变化来自：

- 自适应 gate 学习；
- 还是随机初始化导致的融合扰动。

采用：

```python
nn.init.zeros_(self.gate_mlp[-1].weight)
nn.init.zeros_(self.gate_mlp[-1].bias)
```

并令：

```text
fusion_init = 0.1
```

可以保证训练开始时：

[
\beta_j=0.1,\qquad \forall j.
]

因此新模型初始化时应满足：

[
Z_{\text{M2}}=E+0.1I,
]

与当前 M1 完全一致，仅在训练后逐渐学会位置相关的融合权重。

这是本次修复最重要的安全设计。

# 十一、增加 geometry fusion 计算函数

```python
def _compute_fusion_weight(
    self,
    rendered_event,
    delta,
    confidence,
):
    """
    Compute the residual injection weight.

    Geometry fusion is intentionally disabled for the wo_guidance
    ablation, which falls back to a constant initial weight.
    """
    if self.fusion_mode == "fixed":
        beta = self._build_constant_fusion_weight(
            reference=rendered_event,
            value=self.gs_residual_weight,
        )
        return beta, None

    if self.fusion_gate is None:
        raise RuntimeError(
            "fusion_gate is not initialized while "
            "fusion_mode='geometry'"
        )

    # wo_guidance must remove both Jet guidance and field-aware
    # fusion guidance.
    if self.ablation_mode == "wo_guidance":
        beta = self._build_constant_fusion_weight(
            reference=rendered_event,
            value=self.fusion_init,
        )
        return beta, None

    if not torch.is_tensor(delta):
        raise TypeError(
            "delta must be a tensor for geometry fusion"
        )

    if confidence is None:
        raise ValueError(
            "confidence must not be None for geometry fusion"
        )

    delta_for_fusion = delta
    confidence_for_fusion = confidence

    if self.fusion_detach_geometry:
        delta_for_fusion = (
            delta_for_fusion.detach()
        )
        confidence_for_fusion = (
            confidence_for_fusion.detach()
        )

    max_shift_local = (
        self.jet_max_shift_samples
        / float(self.patch_len - 1)
    )

    beta, geometry_features = self.fusion_gate(
        confidence=confidence_for_fusion,
        delta=delta_for_fusion,
        max_shift_local=max_shift_local,
    )

    return beta, geometry_features
```

# 十三、为什么 `jet_detach_geometry` 和 `fusion_detach_geometry` 要分开

不要直接让一个 detach 参数同时管理两者。

它们控制的是不同梯度路径：

[
\mathcal L
\rightarrow
\text{Jet}
\rightarrow
(\Delta,C)
\rightarrow
(\mu,\sigma,\alpha),
]

以及：

[
\mathcal L
\rightarrow
\text{Fusion Gate}
\rightarrow
(\Delta,C)
\rightarrow
(\mu,\sigma,\alpha).
]

本次第二修复应保持故事 A 的非对称、单向指导：

```text
jet_detach_geometry = True
fusion_detach_geometry = True
```

这样新增 gate 只学习：

> 如何使用显式几何统计控制局部证据注入。

它不会反过来改变显式高斯几何。

未来若要研究联合优化，可以分别打开两个开关，而不是一次性改变所有梯度路径。

# 十六、不同消融模式的预期行为

行为：

[

## Gaussian only

```text
ablation_mode = gaussian_only
```

行为：

- `use_residual=False`
- 不创建或不使用 fusion gate；
- 输出仅为显式 Gaussian field。

## Linear only

```text
ablation_mode = linear_only
```

行为：

- 直接进入 `PatchLinearRepresentation`；
- 不使用 Gaussian field、Jet 或 fusion gate。

## w/o Jet

```text
ablation_mode = wo_jet
fusion_mode = geometry
```

行为：

- `GaussianJetProjection` 只返回 `base_projection`；
- geometry-conditioned gate 仍然控制 observation pathway；
- 该消融只移除 Gaussian tangent coordinate。

当前 `wo_jet` 已经只返回 base projection，因此不需要改动。

## w/o Guidance

```text
ablation_mode = wo_guidance
fusion_mode = geometry
```

行为：

- `delta=0`
- Jet 不使用 geometry shift；
- `confidence=None`，Jet 按当前逻辑退回常量；
- fusion gate 退回固定 `fusion_init`；
- 所有显式场到局部通路的几何指导均被移除。

## w/o Adaptive Fusion

```text
ablation_mode = wo_adaptive_fusion
```

行为：

- 保留 `delta/confidence` 对 Gaussian Jet 的指导；
- 最终融合恢复固定 `gs_residual_weight`；
- 专门验证 geometry-conditioned coupling 的贡献。

这是第二修复后必须新增的消融。

## 测试 5：gate 参数存在梯度

完成一次 backward 后：

```python
gate_grads = [
    parameter.grad
    for parameter in encoder.fusion_gate.parameters()

    grad is not None
    and torch.isfinite(grad).all()
    for grad in gate_grads
)
```

注意：最后一层零初始化时，第一次 backward 可能只有最后一层得到明显梯度；这是正常的。第二次 optimizer step 后，前层应开始收到梯度。

# 十八、训练期间必须记录的统计量

每个 epoch 或每若干 step 记录：

```text
fusion_gate_mean
fusion_gate_std
fusion_gate_min
fusion_gate_max
fusion_gate_low_ratio
fusion_gate_high_ratio
geometry_uncertainty_mean
geometry_shift_ratio_mean
delta_saturation_ratio
confidence_mean
confidence_std
```

建议定义：

```python
low_ratio = (
    beta < 0.05 * beta_max
).float().mean()

high_ratio = (
    beta > 0.95 * beta_max
).float().mean()
```

合理现象：

- 初始化时 `gate_mean ≈ fusion_init`；
- 初始化时 `gate_std ≈ 0`；
- 训练后 `gate_std` 应逐渐大于零；
- 不同 patch 和样本出现不同权重；
- 不应很快全部压到 0 或 `beta_max`。

需要警惕：

```text
gate_std 长期接近 0
```

说明 gate 没有学到自适应性。

```text
high_ratio 长期大于 80%
```

说明 residual pathway 可能压过显式场。

```text
low_ratio 长期大于 80%
```

说明 gate collapse 到关闭局部通路。

# 二十一、验收标准

Antigravity 完成后必须满足：

-  旧脚本不传 fusion 参数时，默认保持 `fixed` 行为；
-  `fusion_mode=fixed` 与当前 M1 数值严格一致；
-  `fusion_mode=geometry` 初始化时与 M1 数值近似一致；
-  geometry gate 输入只有 coverage uncertainty 和 normalized shift；
-  gate 输出 shape 为 `(B*C, patch_num, 1)`；
-  gate 输出严格位于 `(0, beta_max)`；
-  geometry gate 控制整个 `res_proj`；
-  Jet 内部 confidence 机制保持不变；
-  `wo_guidance` 同时移除 Jet geometry guidance 和 geometry fusion；
-  `wo_jet` 仅移除 Gaussian Jet，保留 geometry fusion；
-  `gaussian_only` 完全绕过 residual 和 fusion；
-  `fusion_detach_geometry=True` 时不会产生从 gate 到显式几何的梯度；
-  新增 `wo_adaptive_fusion` 消融；
-  不修改第一优先级 patch-center 修复；
-  不改变模型输出 shape；
-  所有单元测试通过；
-  训练日志能够报告 gate 分布。

# 可直接发送给 Antigravity 的精简指令

```text
请将当前固定残差融合

    rendered_event
    + gs_residual_weight * res_proj

修改为低风险的 geometry-conditioned residual fusion：

    rendered_event
    + beta * res_proj

其中 beta 的形状为 (batch_channel, patch_num, 1)，由显式场已经
计算出的 confidence 和 delta 生成。

具体要求：

1. 新建 GeometryConditionedResidualGate。
2. Gate 输入固定为：
       uncertainty = clamp(1 - confidence, 0, 1)
       shift_magnitude =
           clamp(abs(delta) / max_shift_local, 0, 1)
3. Gate 使用一个轻量 2→hidden→1 MLP，默认 hidden=16。
4. 输出：
       beta = beta_max * sigmoid(base_logit + gate_mlp(features))
5. 令：
       base_logit = logit(fusion_init / beta_max)
6. Gate MLP 最后一层权重和偏置必须初始化为 0，使训练开始时：
       beta == fusion_init
   对所有样本和 patch 严格成立。
7. 默认：
       fusion_init = 0.1
       fusion_beta_max = 0.5
       fusion_detach_geometry = True
8. 保留 fusion_mode：
       fixed
       geometry
   旧配置默认 fixed，以保证旧实验和 checkpoint 兼容。
9. fixed 模式必须严格复现：
       rendered_event
       + gs_residual_weight * res_proj
10. geometry 模式必须控制整个 res_proj，而不是只控制 Jet 项。
11. 保留 GaussianJetProjection 内部现有的 confidence 调制。
12. jet_detach_geometry 和 fusion_detach_geometry 必须分开。
13. 默认两者均为 True，本次不做双向联合优化。
14. wo_guidance 时：
       delta = 0
       Jet 不接收 geometry guidance
       fusion beta 退回常数 fusion_init
15. wo_jet 时：
       只移除 Gaussian Jet
       geometry fusion 仍可控制 base observation pathway
16. gaussian_only 时完全绕过 residual 与 fusion。
17. 增加 wo_adaptive_fusion 消融，该模式保留 Jet guidance，
    但恢复固定 gs_residual_weight。
18. 增加 last_fusion_gate、last_fusion_features、last_delta、
    last_confidence 诊断状态，全部保存 detach 后的张量。
19. 修改 use_residual 的启用条件：
       fixed 模式依据 gs_residual_weight
       geometry 模式依据 fusion_beta_max
20. 更新 gs_linear.py 和参数解析器，加入：
       fusion_mode
       fusion_hidden_dim
       fusion_init
       fusion_beta_max
       fusion_detach_geometry
21. 保证 geometry 模式在初始化时与 fixed=0.1 模式前向输出一致。
22. 不修改第一阶段 patch_centers、Gaussian renderer、CAS、
    local scale、forecasting head 或 q0 + delta*q1。
23. 增加初始化等价性、输出范围、detach、ablation、混合精度和
    backward 梯度单元测试。
```

第二修复完成后，架构的核心关系会从：

[
\text{field guidance inside Jet}
+
\text{fixed route addition}
]

升级为：

[
\boxed{
\text{field-guided local analysis}
+
\text{field-conditioned observation injection}
}
]

这正是故事 A+ 中最关键的架构闭环。
