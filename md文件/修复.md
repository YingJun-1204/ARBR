建议把两个问题分开修改、分开验证。**先修正 `w/o Field Guidance` 的消融定义，再尝试精确归一化导数**。前者只影响消融结果；后者会改变完整模型，需要重新训练和可能的 HPO。

# 1. 将 `w/o Field Guidance` 改成更严格、更公平的消融

当前实现是：

- (\Delta_j=0)；
- `confidence=None`，随后在 Jet 内部隐式替换为 (1)；
- coupling 固定为 `fusion_init`。

这确实移除了 field guidance，但冻结 coupling 会使性能差距同时包含“没有几何自适应”和“不能学习全局融合强度”两个因素。

更适合论文的定义是：

[
\Delta_j=0,\qquad C_j=1,\qquad
\beta_j=\beta_{\mathrm{global}}
=\beta_{\max}\operatorname{sigmoid}(\theta_\beta),
]

其中 (\theta_\beta) 是一个**可学习但与样本和 patch 无关的全局标量**。这样消融只移除：

- field-derived transport；
- field-derived coverage modulation；
- geometry-conditioned adaptive coupling；

但仍允许局部观察分支学习一个合理的总体贡献比例。

## 1.1 修改 `splatting_residual_encoder.py` 的初始化

在创建 `fusion_gate` 后加入：

```python
# Global sample-independent coupling used only by the
# w/o Field Guidance ablation.
if (
    self.use_residual
    and self.fusion_mode == "geometry"
    and self.ablation_mode == "wo_guidance"
):
    init_ratio = self.fusion_init / self.fusion_beta_max
    global_fusion_logit = math.log(
        init_ratio / (1.0 - init_ratio)
    )
    self.wo_guidance_fusion_logit = nn.Parameter(
        torch.tensor(
            global_fusion_logit,
            dtype=torch.float32,
        )
    )
else:
    self.register_parameter(
        "wo_guidance_fusion_logit",
        None,
    )
```

由于文件已经导入 `math`，不需要增加 import。

## 1.2 修改 `_compute_fusion_weight`

将当前代码：

```python
if self.ablation_mode == "wo_guidance":
    beta = self._build_constant_fusion_weight(
        reference=rendered_event,
        value=self.fusion_init,
    )
    return beta, None
```

替换为：

```python
if self.ablation_mode == "wo_guidance":
    if self.wo_guidance_fusion_logit is None:
        raise RuntimeError(
            "The global fusion logit is not initialized "
            "for the wo_guidance ablation."
        )

    global_logit = self.wo_guidance_fusion_logit.to(
        device=rendered_event.device,
        dtype=rendered_event.dtype,
    )

    beta_scalar = self.fusion_beta_max * torch.sigmoid(
        global_logit
    )

    beta = beta_scalar.view(1, 1, 1).expand(
        rendered_event.shape[0],
        rendered_event.shape[1],
        1,
    )

    return beta, None
```

完整模型仍使用由 ([1-C_j,\rho_j]) 输入 MLP 产生的 patch-dependent (\beta_j)；这里只把它替换成可学习的全局标量，因此控制变量更干净。

## 1.3 显式构造零位移和单位 coverage

将：

```python
if self.ablation_mode == "wo_guidance":
    delta_raw = 0.0
    confidence_raw = None
```

替换为：

```python
if self.ablation_mode == "wo_guidance":
    geometry_shape = (
        rendered_event.shape[0],
        rendered_event.shape[1],
        1,
    )

    delta_raw = rendered_event.new_zeros(
        geometry_shape
    )
    confidence_raw = rendered_event.new_ones(
        geometry_shape
    )
```

这与当前 Jet 中 `confidence=None -> 1.0` 的数值行为一致，但不再依赖隐藏 fallback，并且张量形状、日志和诊断信息都与完整模型保持一致。当前 fallback 位于 `GaussianJetProjection.forward`。

## 1.4 修改后的消融数学定义

该变体最终成为：

[
q_j^{\mathrm{jet}}=q_j^{(0)},
]

# [ I_j^{\mathrm{no\text{-}guide}}

b_j+\eta W_Gq_j^{(0)},
]

# [ Z_j^{\mathrm{no\text{-}guide}}

E_j+\beta_{\mathrm{global}}
I_j^{\mathrm{no\text{-}guide}}.
]

论文可以准确写为：

```latex
\textit{w/o Field Guidance} removes field-derived guidance from both
the local operator and the coupling mechanism. Specifically, it sets
$\Delta_j=0$ and $C_j=1$, reducing the Gaussian Jet to its canonical
zero-order response, and replaces the geometry-conditioned coupling
weight with a learned sample-independent scalar
$\beta_{\mathrm{global}}\in(0,\beta_{\max})$.
The field representation and local observation pathway are otherwise
retained.
```

这个版本比固定 `fusion_init` 更适合支撑“field guidance 的贡献”，因为性能差距不能被解释为消融模型没有机会学习合适的总体融合比例。

# 2. 将 Gaussian Jet 改成精确的归一化 Gaussian 中心导数

当前代码先归一化 (\phi)，随后计算：

```python
psi = (d_mesh / (sigma**2 + eps)) * phi
psi = psi - psi.mean(dim=-1, keepdim=True)
```

这不是归一化 basis 关于中心参数的精确导数。

对于：

# [ \bar\phi_{mr}

# \exp\left( -\frac{(u_r-\nu_m)^2} {2s_m^2+\epsilon} \right), \qquad \phi_{mr}

\frac{\bar\phi_{mr}}
{\sum_s\bar\phi_{ms}+\epsilon},
]

定义：

# [ a_{mr}

\frac{2(u_r-\nu_m)}
{2s_m^2+\epsilon}.
]

则精确导数为：

# [ \frac{\partial\phi_{mr}}{\partial\nu_m}

## \phi_{mr} \left( a_{mr}

\sum_s\phi_{ms}a_{ms}
\right).
]

第二项是归一化分母产生的修正，不是普通算术均值。

## 2.1 推荐增加可切换模式

因为你准备先试验，建议暂时同时保留旧实现和精确实现。

在 `GaussianJetProjection.__init__` 中增加：

```python
jet_derivative_mode="exact",
```

随后加入：

```python
if jet_derivative_mode not in {
    "exact",
    "centered_legacy",
}:
    raise ValueError(
        "jet_derivative_mode must be either "
        "'exact' or 'centered_legacy', "
        f"got {jet_derivative_mode}"
    )

self.jet_derivative_mode = jet_derivative_mode
```

## 2.2 完整替换 `_build_gaussian_jet`

```python
def _build_gaussian_jet(self, device, dtype):
    t = torch.linspace(
        0,
        1,
        self.patch_len,
        device=device,
        dtype=dtype,
    )

    mu = self.g_mu.view(-1, 1).to(
        device=device,
        dtype=dtype,
    )

    sigma = (
        F.softplus(self.g_sigma) + 0.03
    ).view(-1, 1).to(
        device=device,
        dtype=dtype,
    )

    d_mesh = t.view(1, -1) - mu
    eps = 1e-5

    # Zero-order epsilon-stabilized normalized Gaussian basis.
    gaussian_denom = 2.0 * sigma.square() + eps

    phi_raw = torch.exp(
        -d_mesh.square() / gaussian_denom
    )

    phi = phi_raw / (
        phi_raw.sum(dim=-1, keepdim=True) + eps
    )

    if self.jet_derivative_mode == "exact":
        # Exact derivative of the normalized Gaussian basis
        # with respect to its center mu.
        center_score = (
            2.0 * d_mesh / gaussian_denom
        )

        normalized_score_mean = (
            phi * center_score
        ).sum(
            dim=-1,
            keepdim=True,
        )

        psi = phi * (
            center_score - normalized_score_mean
        )

    elif self.jet_derivative_mode == "centered_legacy":
        # Original derivative-inspired implementation,
        # retained only for controlled comparison.
        psi = (
            d_mesh / (sigma.square() + eps)
        ) * phi

        psi = psi - psi.mean(
            dim=-1,
            keepdim=True,
        )

    else:
        raise RuntimeError(
            "Unexpected jet derivative mode: "
            f"{self.jet_derivative_mode}"
        )

    return phi, psi
```

这里没有对精确导数再执行：

```python
psi = psi - psi.mean(...)
```

因为额外的普通均值中心化会再次破坏精确导数关系。

# 4. 精确导数的数值检查

在开始完整训练前，先用有限差分验证实现。下面的检查应当在 `float64` 下获得很小的误差：

```python
import torch
import torch.nn.functional as F

@torch.no_grad()
def check_exact_gaussian_derivative(
    layer,
    step=1e-5,
):
    device = layer.g_mu.device
    dtype = torch.float64

    t = torch.linspace(
        0,
        1,
        layer.patch_len,
        device=device,
        dtype=dtype,
    )

    mu = layer.g_mu.detach().to(dtype).view(-1, 1)
    sigma = (
        F.softplus(layer.g_sigma.detach().to(dtype))
        + 0.03
    ).view(-1, 1)

    eps = 1e-5

    def build_phi(current_mu):
        d = t.view(1, -1) - current_mu
        denom = 2.0 * sigma.square() + eps
        raw = torch.exp(-d.square() / denom)
        return raw / (
            raw.sum(dim=-1, keepdim=True) + eps
        )

    phi = build_phi(mu)

    denom = 2.0 * sigma.square() + eps
    score = 2.0 * (
        t.view(1, -1) - mu
    ) / denom

    psi_exact = phi * (
        score
        - (phi * score).sum(
            dim=-1,
            keepdim=True,
        )
    )

    errors = []

    for m in range(mu.shape[0]):
        mu_plus = mu.clone()
        mu_minus = mu.clone()

        mu_plus[m, 0] += step
        mu_minus[m, 0] -= step

        phi_plus = build_phi(mu_plus)[m]
        phi_minus = build_phi(mu_minus)[m]

        finite_difference = (
            phi_plus - phi_minus
        ) / (2.0 * step)

        error = (
            finite_difference - psi_exact[m]
        ).abs().max().item()

        errors.append(error)

    max_error = max(errors)
    print(
        "Maximum finite-difference error:",
        max_error,
    )

    return max_error
```

建议判断标准：

```python
assert max_error < 1e-4
```

在 GPU 或较低精度下可适当放宽，但应先用 CPU `float64` 检查。

# 5. 改动后的论文理论可以怎样写

精确导数生效后，理论关系可以严格写成：

# [ q_{jm}(\nu_m+\Delta_j)

q_{jm}(\nu_m)
+
\Delta_j
\frac{\partial q_{jm}(\nu_m)}
{\partial\nu_m}
+
\mathcal O(\Delta_j^2),
]

其中：

# [ q_{jm}^{(1)}

\left\langle
p_j,
\frac{\partial\phi_m}{\partial\nu_m}
\right\rangle.
]

Appendix 中必须使用**归一化 Gaussian 的完整导数**，不能继续只写：

# [ \frac{\partial\phi_m}{\partial\nu_m}

\frac{u-\nu_m}{s_m^2}\phi_m,
]

因为该式只直接适用于未归一化 Gaussian。当前论文附录使用的是简单未归一化导数，但实现中的 basis 又进行了归一化，因此即使代码改成 B，论文推导也需要同步补上归一化修正项。

# 6. 推荐试验顺序

1. **先改 `w/o Field Guidance`**：完整模型不受影响，只需重跑该消融。
2. **再启用 `jet_derivative_mode=exact`**：先保持原有 HPO 参数不变，确认纯实现变化的影响。
3. 精确导数效果稳定或更好后，再对完整模型进行 HPO。
4. 精确导数明显变差时，直接切回 `centered_legacy`，论文采用路径 A + MSE + 收缩主张。

不要同时启用辅助 loss。否则当结果变化时，无法区分是精确导数还是训练目标变化造成的。
