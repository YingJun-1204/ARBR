下面这份可以直接作为 **Antigravity 的修复任务说明**。第一优先级的目标很纯粹：

[
\boxed{
\text{让显式高斯场的查询位置、Gaussian guidance 的参考位置、真实 patch 的位置完全一致}
}
]

当前有三套相关坐标：

- 显式场用 `torch.linspace(0, 1, patch_num)` 查询；
- guidance 又独立创建一次 `torch.linspace(0, 1, patch_num)`；
- Gaussian Jet 实际处理的是由 `unfold(patch_len, stride)` 得到的窗口。

前两者只是理想化均匀点，第三者才是真实 patch 支持，因此现在只是张量索引相同，物理时间位置并不严格相同。

# 二、修复目标

完成后必须满足：

1. 每个 patch 只有一个唯一的全局时间中心；
2. 显式 Gaussian renderer 使用这些真实 patch center；
3. Gaussian score shift 使用同一组 patch center；
4. `delta` 从全序列归一化坐标转换为 patch 局部归一化坐标；
5. `jet_max_shift_samples=1.0` 仍表示最多移动约一个原始采样点；
6. 模型输出形状、参数量、head 接口保持不变；
7. 不引入新可训练参数；
8. 不修改 guidance 的正负方向、Jet 公式或融合方式。

# 三、真实 patch center 应如何计算

设：

[
L=\text{seq_len},\qquad
P=\text{patch_len},\qquad
S=\text{stride}.
]

第 (j) 个 patch 的起点为：

[
s_j=jS.
]

其内部采样位置为：

[
s_j,\ s_j+1,\ldots,s_j+P-1.
]

由于当前使用右侧 `ReplicationPad1d`，超出序列的索引实际对应最后一个时间点 (L-1)。因此应定义有效索引：

# [ \tilde{s}_{jr}

\min(s_j+r,L-1).
]

第 (j) 个 patch 的时间中心定义为：

# [ t_j

\frac{1}{L-1}
\frac{1}{P}
\sum_{r=0}^{P-1}\tilde{s}_{jr}.
]

这样：

- 无 padding 时，它就是标准窗口中点；
- 有 padding 时，它会考虑最后一个观测被重复使用；
- (t_j\in[0,1])；
- 与真实 `ReplicationPad1d + unfold` 一致。

不要直接用：

```python
torch.linspace(0, 1, patch_num)
```

也不建议只简单使用：

```python
min(j * stride + (patch_len - 1) / 2, seq_len - 1)
```

因为后者没有准确反映 replication padding 中最后一个样本被重复多次的事实。

## 4.2 增加真实 patch center 构造函数

建议作为类中的静态方法：

```python
@staticmethod
def _build_patch_centers(
    seq_len: int,
    patch_len: int,
    stride: int,
    patch_num: int,
) -> torch.Tensor:
    """
    Build normalized temporal centroids of the actual patches produced
    by ReplicationPad1d followed by unfold.

    Each center is expressed in the global input coordinate [0, 1].
    Right-padded samples are mapped to the final valid input index.
    """
    starts = (
        torch.arange(patch_num, dtype=torch.float32)
        .unsqueeze(1)
        * float(stride)
    )

    offsets = torch.arange(
        patch_len,
        dtype=torch.float32,
    ).unsqueeze(0)

    sampled_indices = starts + offsets

    # Match right-side replication padding:
    # indices beyond seq_len - 1 correspond to the final observation.
    effective_indices = sampled_indices.clamp(
        max=float(seq_len - 1)
    )

    centers = effective_indices.mean(dim=1)
    centers = centers / float(seq_len - 1)

    return centers
```

然后在 `__init__` 中注册：

```python
patch_centers = self._build_patch_centers(
    seq_len=self.seq_len,
    patch_len=self.patch_len,
    stride=self.stride,
    patch_num=self.patch_num,
)

self.register_buffer(
    "patch_centers",
    patch_centers,
    persistent=False,
)
```

使用 `persistent=False` 的原因是：

- 它不是可学习参数；
- 它可以由配置重新确定；
- 不写入 checkpoint；
- 旧 checkpoint 不会因为缺少 `patch_centers` 而加载失败。

# 七、修正 `delta` 的坐标单位

## 7.1 当前单位问题

显式参数：

[
\mu,\sigma,t_j
]

位于全序列归一化坐标：

[
[0,1]_{\text{global}}.
]

因此：

[
\mu-t_j
]

表示的是全序列归一化位移。

但 Gaussian Jet 中：

```python
t = torch.linspace(0, 1, patch_len)
```

表示 patch 内部局部坐标：

[
[0,1]_{\text{local}}.
]

因此传给：

[
q_0+\Delta q_1
]

的 (\Delta) 必须是 patch 局部归一化位移。

一个原始采样点分别对应：

[
\frac{1}{L-1}
\quad\text{和}\quad
\frac{1}{P-1}.
]

所以全局位移转换为局部位移时：

# [ \Delta_{\mathrm{local}}

\Delta_{\mathrm{global}}
\frac{L-1}{P-1}.
]

当前 `_compute_gaussian_score_shift()` 把全局 `mean_shift` 直接与局部 `max_shift` 比较，单位不一致。

## 7.3 正确计算 local delta

建议将变量名写清楚，不要继续笼统使用 `mean_shift`：

```python
distance_global = (
    t.view(1, patch_num, 1)
    - mu.unsqueeze(1)
)

eps = 1e-5

score_weights = (
    alpha_effective.unsqueeze(1)
    * torch.exp(
        -(distance_global ** 2)
        / (2 * sigma.unsqueeze(1) ** 2 + eps)
    )
)

precision_global = 1.0 / (
    sigma.unsqueeze(1) ** 2 + eps
)

weighted_precision = score_weights * precision_global

mean_shift_global = (
    weighted_precision
    * (
        mu.unsqueeze(1)
        - t.view(1, patch_num, 1)
    )
).sum(dim=-1, keepdim=True) / (
    weighted_precision.sum(
        dim=-1,
        keepdim=True,
    )
    + eps
)
```

然后进行单位转换：

```python
global_to_local = (
    float(self.seq_len - 1)
    / float(self.patch_len - 1)
)

mean_shift_local = (
    mean_shift_global
    * global_to_local
)
```

`jet_max_shift_samples` 继续按“原始样本点数”解释：

```python
max_shift_local = (
    self.jet_max_shift_samples
    / float(self.patch_len - 1)
)
```

最终：

```python
delta_local = (
    max_shift_local
    * torch.tanh(
        self.jet_score_temperature
        * mean_shift_local
        / (max_shift_local + eps)
    )
)
```

完整后半段：

```python
density = score_weights.sum(
    dim=-1,
    keepdim=True,
)

confidence = density / (
    density + self.jet_density_tau
)

return delta_local, confidence
```

这样：

[
|\Delta_{\mathrm{local}}|
\leq
\frac{\texttt{jet_max_shift_samples}}{P-1}.
]

当 `jet_max_shift_samples=1.0` 时，Jet 最多沿 patch 局部坐标移动一个原始采样点对应的距离。

# 九、推荐的完整函数版本

Antigravity 可以直接按下面的结构重写：

```python
def _compute_gaussian_score_shift(
    self,
    mu,
    sigma,
    alpha_effective,
    query_positions,
):
    """
    Compute field-derived displacement in the local normalized
    coordinate of each patch.

    mu, sigma and query_positions use the global input coordinate.
    The returned delta uses the local patch coordinate expected by
    GaussianJetProjection.
    """
    t = query_positions.to(
        device=mu.device,
        dtype=mu.dtype,
    )

    if t.ndim != 1:
        raise ValueError(
            "query_positions must be one-dimensional, "
            f"got shape {tuple(t.shape)}"
        )

    patch_num = t.numel()
    eps = 1e-5

    t_expanded = t.view(1, patch_num, 1)

    distance_global = (
        t_expanded - mu.unsqueeze(1)
    )

    score_weights = (
        alpha_effective.unsqueeze(1)
        * torch.exp(
            -(distance_global ** 2)
            / (
                2 * sigma.unsqueeze(1) ** 2
                + eps
            )
        )
    )

    precision_global = 1.0 / (
        sigma.unsqueeze(1) ** 2 + eps
    )

    weighted_precision = (
        score_weights * precision_global
    )

    mean_shift_global = (
        weighted_precision
        * (
            mu.unsqueeze(1)
            - t_expanded
        )
    ).sum(
        dim=-1,
        keepdim=True,
    ) / (
        weighted_precision.sum(
            dim=-1,
            keepdim=True,
        )
        + eps
    )

    global_to_local = (
        float(self.seq_len - 1)
        / float(self.patch_len - 1)
    )

    mean_shift_local = (
        mean_shift_global
        * global_to_local
    )

    max_shift_local = (
        self.jet_max_shift_samples
        / float(self.patch_len - 1)
    )

    delta_local = (
        max_shift_local
        * torch.tanh(
            self.jet_score_temperature
            * mean_shift_local
            / (max_shift_local + eps)
        )
    )

    density = score_weights.sum(
        dim=-1,
        keepdim=True,
    )

    confidence = density / (
        density + self.jet_density_tau
    )

    return delta_local, confidence
```
