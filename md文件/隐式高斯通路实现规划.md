# Splat-Guided Gaussian Jet Adapter 实现规划

## 一、修改背景

当前模型采用显式高斯通路与线性残差通路组成双路表示：

- 显式通路通过 Temporal Gaussian Splatting 建模连续时间位置、尺度、强度和潜在特征；
- 线性通路负责补充高频、尖峰及高斯通路不容易表达的非平稳细节。

为了给线性投影加入抗局部平移能力，当前实现在线性层外构造了动态高斯调制壳。具体过程是为每个样本、每个 patch 和每个隐藏维度生成高斯调制矩阵：

[
M\in\mathbb{R}^{BC\times P\times D\times L}
]

再显式构造：

[
W_{\mathrm{dynamic}}=W_{\mathrm{base}}\odot M
]

这会产生多个尺寸为 `[B*C, patch_num, d_model, patch_len]` 的大张量，包括 `M_modulator`、`W_dynamic` 以及投影乘法的中间结果，造成显存占用和训练时间显著增加。

此外，当前残差分支采用两阶段投影：

1. 第一次普通线性投影用于给路由器计算局部状态；
2. 路由器输出方向后，再执行第二次动态高斯线性投影。

因此，线性通路实际上执行了两次 patch 投影，并保留了较大的动态计算图，是训练时间接近翻倍的另一主要原因。

本次修改需要同时实现三个目标：

1. **降低显存和计算量**

   不再显式生成 `[B*C, P, D, L]` 的动态权重或调制矩阵；删除第一次基础线性投影，将残差分支恢复为单次投影。

2. **保留并强化隐式高斯思想**

   线性通路不能退化成纯插值对齐加普通 Linear，而应继续具有明确的高斯参数化，与显式 Gaussian Splatting 形成“显式高斯—隐式高斯”双路结构。

3. **增强理论创新性**

   不再把高斯仅作为经验性的平滑 mask，而是利用显式高斯密度产生解析局部位移，并通过高斯基函数及其一阶导数，对线性表示进行小平移下的一阶 Taylor 校正。

最终模块命名建议为：

> **Splat-Guided Gaussian Jet Adapter，SG-GJA**

对应代码模块建议命名为：

```python
GaussianJetProjection
```

------

# 二、总体实现思路

## 2.1 显式高斯通路保持主体不变

显式通路继续使用现有 `TemporalGaussianSplatting`，输出：

```python
rendered_event
weights
mu
sigma
alpha_effective
```

当前显式模块已经提供实现解析位移所需的高斯中心、尺度和强度，因此不需要新增一个 MLP 来预测平移量。

------

## 2.2 从显式高斯参数解析计算局部位移

对每个 patch 查询位置 (t_p)，根据显式高斯参数重新计算与原始高斯顺序对齐的几何权重：

# [ \bar w_{p,k}

\alpha_k
\exp
\left(
-\frac{(t_p-\mu_k)^2}{2\sigma_k^2}
\right)
]

然后计算精度加权 mean-shift：

# [ m_p

\frac{
\sum_k
\frac{\bar w_{p,k}}{\sigma_k^2}
(\mu_k-t_p)
}{
\sum_k
\frac{\bar w_{p,k}}{\sigma_k^2}
+\epsilon
}
]

将其限制在最多一至两个采样点：

# [ \delta_p

\delta_{\max}
\tanh
\left(
\frac{\gamma m_p}{\delta_{\max}}
\right)
]

其中：

```python
max_shift_normalized = max_shift_samples / (patch_len - 1)
```

建议第一版配置：

```python
max_shift_samples = 1.0
score_temperature = 1.0
```

同时根据显式高斯覆盖程度生成置信度：

# [ c_p

\frac{\rho_p}{\rho_p+\tau},
\qquad
\rho_p=\sum_k\bar w_{p,k}
]

该置信度用于控制隐式高斯修正强度：

- 显式高斯覆盖充分时，允许较强校正；
- 显式高斯覆盖不足时，自动退回普通线性投影。

### 重要实现要求

不能直接使用 occlusion 分支返回的排序后 `weights` 与未排序的 `mu`、`sigma` 组合，因为启用 occlusion 时二者的高斯索引可能不再对齐。

应当在 `SplattingResidualEncoder` 中利用：

```python
mu
sigma
alpha_effective
```

重新计算一个轻量的：

```python
score_weights  # [B*C, patch_num, num_gaussians]
```

其显存成本很低，并且能够保证索引严格对应。

------

## 2.3 构造隐式 Gaussian Jet

在线性通路中设置 (K) 个共享隐式高斯基函数：

# [ \phi_k(t)

\exp
\left(
-\frac{(t-\nu_k)^2}{2s_k^2}
\right)
]

其中：

- (\nu_k) 为隐式高斯中心；
- (s_k) 为隐式高斯尺度；
- (K) 建议取 4；
- 中心与尺度在所有样本、patch 和输出通道间共享。

对于小幅局部平移：

# [ \phi_k(t-\delta)

\phi_k(t)
+
\delta\psi_k(t)
+
O(\delta^2)
]

其中一阶导数基底为：

# [ \psi_k(t)

\frac{t-\nu_k}{s_k^2}\phi_k(t)
]

因此只需要预先计算两套大小为 `[K, patch_len]` 的静态基底：

```python
phi  # 零阶 Gaussian basis
psi  # 一阶 Gaussian derivative basis
```

不再为每个样本生成完整动态高斯 mask。

------

## 2.4 计算低秩高斯响应

输入 patch 形状为：

```python
patches  # [B*C, patch_num, patch_len]
```

先计算零阶和一阶高斯响应：

[
q_p^{(0)}=x_p\Phi^\top
]

[
q_p^{(1)}=x_p\Psi^\top
]

代码形式：

```python
q0 = torch.einsum("npl,kl->npk", patches, phi)
q1 = torch.einsum("npl,kl->npk", patches, psi)
```

得到：

```python
q0, q1  # [B*C, patch_num, K]
```

再使用显式高斯位移进行一阶平移校正：

# [ q_p^{\mathrm{jet}}

q_p^{(0)}
+
\delta_pq_p^{(1)}
]

代码形式：

```python
q_jet = q0 + delta * q1
```

其中：

```python
delta.shape == [B*C, patch_num, 1]
```

------

## 2.5 与普通线性投影融合

普通线性主干完整保留：

[
z_p^{\mathrm{base}}=Wx_p
]

隐式高斯响应通过低秩上投影映射到 `d_model`：

[
z_p^{\mathrm{jet}}=Uq_p^{\mathrm{jet}}
]

最终输出：

# [ z_p^{\mathrm{implicit}}

z_p^{\mathrm{base}}
+
\lambda c_pz_p^{\mathrm{jet}}
]

代码形式：

```python
base = self.base_projection(patches)
jet = self.gaussian_up(q_jet)

scale = torch.sigmoid(self.adapter_logit)
res_proj = base + scale * confidence * jet
```

其中：

```python
self.gaussian_up = nn.Linear(
    num_implicit_gaussians,
    d_model,
    bias=False,
)
```

### 初始化要求

为了保证新模块训练初始状态严格接近普通线性投影：

```python
nn.init.zeros_(self.gaussian_up.weight)
```

但不能同时把适配器缩放系数初始化为严格的 0，否则 `gaussian_up` 也可能收不到有效梯度。

建议：

```python
self.adapter_logit = nn.Parameter(torch.tensor(-2.2))
```

此时：

```python
sigmoid(-2.2) ≈ 0.10
```

模型初始输出仍然等价于普通 Linear，因为 `gaussian_up.weight` 为零；同时 `gaussian_up` 从第一步起能够获得非零梯度。

------

## 2.6 双路最终融合

保持当前整体融合形式：

```python
rendered_event = (
    rendered_event
    + gs_residual_weight * res_proj
)
```

不再额外乘现有路由器生成的 `gate_scale`。

隐式高斯修正的局部强弱已经由：

```python
confidence
adapter_scale
```

共同控制。

# 三、需要修改的文件

## 3.1 `layers/patch_residual.py`

### 修改级别

核心重构。

### 当前需要删除的实现

删除或弃用当前动态高斯权重相关逻辑：

```python
self.g_coeff
self.shift_scaler

M_modulator
W_dynamic

torch.einsum("ck,bpkt->bpct", ...)
```

删除：

```python
get_base_projection()
```

当前大显存张量和两阶段投影的主要来源都在该文件。

### 建议的新类名

可以直接替换现有类，也可以保留旧类用于消融。

推荐保留旧类，并新增：

```python
class GaussianJetProjection(nn.Module):
```

如果希望最小化调用方改动，也可以保留类名：

```python
class PatchResidualProjection(nn.Module):
```

但内部实现完全替换为 Gaussian Jet。

### 构造函数建议

```python
def __init__(
    self,
    seq_len,
    patch_len,
    stride,
    d_model,
    num_implicit_gaussians=4,
    jet_scale_init=0.1,
    sigma_init=0.20,
    learnable_mu=True,
    learnable_sigma=True,
):
```

### 需要保留的组件

```python
self.padding_patch_layer
self.patch_num
self.base_projection
```

### 需要新增的参数

```python
self.num_implicit_gaussians

self.g_mu
self.g_sigma

self.gaussian_up
self.adapter_logit
```

建议初始化：

```python
self.g_mu = nn.Parameter(
    torch.linspace(0, 1, num_implicit_gaussians)
)

self.g_sigma = nn.Parameter(
    inverse_softplus(
        torch.full((num_implicit_gaussians,), sigma_init)
    )
)

self.gaussian_up = nn.Linear(
    num_implicit_gaussians,
    d_model,
    bias=False,
)

nn.init.zeros_(self.gaussian_up.weight)
```

### 建议新增内部方法

```python
def _extract_patches(self, x_seq):
```

返回：

```python
patches  # [B*C, patch_num, patch_len]
```

新增：

```python
def _build_gaussian_jet(self, device, dtype):
```

返回归一化后的：

```python
phi  # [K, patch_len]
psi  # [K, patch_len]
```

建议对 `phi` 做 L1 归一化：

```python
phi = phi / (phi.sum(dim=-1, keepdim=True) + eps)
```

`psi` 应从归一化后的 `phi` 推导：

```python
psi = (
    (t - mu) / (sigma ** 2 + eps)
) * phi
```

为减少一阶导数的离散偏置，可以再执行：

```python
psi = psi - psi.mean(dim=-1, keepdim=True)
```

确保导数基底对常量输入的响应接近零。

### 新 forward 接口

建议：

```python
def forward(
    self,
    x_seq,
    delta,
    confidence=None,
):
```

其中：

```python
delta      # [B*C, patch_num, 1]
confidence # [B*C, patch_num, 1]
```

forward 过程：

```python
patches = self._extract_patches(x_seq)

base = self.base_projection(patches)

phi, psi = self._build_gaussian_jet(
    patches.device,
    patches.dtype,
)

q0 = torch.einsum("npl,kl->npk", patches, phi)
q1 = torch.einsum("npl,kl->npk", patches, psi)

q_jet = q0 + delta * q1
jet = self.gaussian_up(q_jet)

if confidence is None:
    confidence = 1.0

scale = torch.sigmoid(self.adapter_logit)

return base + scale * confidence * jet
```

### 调试状态建议

保存以下诊断值，但必须使用 `detach()`：

```python
self.last_phi
self.last_psi
self.last_q0
self.last_q1
self.last_jet_norm
self.last_base_norm
self.last_adapter_scale
```

不要长期保存完整 batch 的计算图。

## 3.2 `layers/splatting_residual_encoder.py`

### 修改级别

核心接线重构。

### 构造函数新增配置

建议增加：

```python
residual_mode="gaussian_jet"
num_implicit_gaussians=4
jet_max_shift_samples=1.0
jet_score_temperature=1.0
jet_density_tau=1.0
jet_detach_geometry=True
jet_scale_init=0.1
jet_sigma_init=0.2
```

### 初始化残差模块

当：

```python
residual_mode == "gaussian_jet"
```

时，创建：

```python
self.patch_residual = GaussianJetProjection(...)
```

旧的动态高斯壳和 `AdaptiveResidualRouter` 暂时保留，用于复现实验和后续消融：

```python
residual_mode == "legacy_dynamic_shell"
```

不要直接删除旧模式。

### 新增解析位移函数

建议在该文件增加私有方法：

```python
def _compute_gaussian_score_shift(
    self,
    mu,
    sigma,
    alpha_effective,
    patch_num,
    device,
):
```

输入形状：

```python
mu              # [B*C, num_gaussians]
sigma           # [B*C, num_gaussians]
alpha_effective # [B*C, num_gaussians]
```

内部重新生成查询点：

```python
t = torch.linspace(
    0,
    1,
    patch_num,
    device=device,
    dtype=mu.dtype,
)
```

计算与高斯参数严格对齐的权重：

```python
distance = (
    t.view(1, patch_num, 1)
    - mu.unsqueeze(1)
)

score_weights = (
    alpha_effective.unsqueeze(1)
    * torch.exp(
        -(distance ** 2)
        / (2 * sigma.unsqueeze(1) ** 2 + eps)
    )
)
```

计算精度加权位移：

```python
precision = 1.0 / (
    sigma.unsqueeze(1) ** 2 + eps
)

weighted_precision = score_weights * precision

mean_shift = (
    weighted_precision
    * (
        mu.unsqueeze(1)
        - t.view(1, patch_num, 1)
    )
).sum(dim=-1, keepdim=True) / (
    weighted_precision.sum(
        dim=-1,
        keepdim=True,
    )
    + eps
)
```

限制偏移范围：

```python
max_shift = (
    self.jet_max_shift_samples
    / max(self.patch_len - 1, 1)
)

delta = max_shift * torch.tanh(
    self.jet_score_temperature
    * mean_shift
    / (max_shift + eps)
)
```

计算置信度：

```python
density = score_weights.sum(
    dim=-1,
    keepdim=True,
)

confidence = density / (
    density + self.jet_density_tau
)
```

### 是否反向传播到显式高斯通路

第一版建议默认：

```python
jet_detach_geometry = True
```

执行：

```python
delta = delta.detach()
confidence = confidence.detach()
```

原因：

- 避免隐式适配器的梯度直接干扰显式 Gaussian Splatting；
- 减少显式与隐式通路之间的反向图耦合；
- 提高训练稳定性；
- 更接近“显式通路提供几何先验”的设计。

但必须保留配置开关，以便论文消融：

```python
jet_detach_geometry=False
```

测试端到端联合优化是否进一步提升性能。

### 修改 forward 流程

当前三阶段流程：

```python
res_proj_base = self.patch_residual.get_base_projection(...)

gate_scale, gate_direction, ... = self.residual_router(...)

res_proj = self.patch_residual(
    ...,
    gate_direction=gate_direction,
)
```

需要在 Gaussian Jet 模式下全部移除。

改为：

```python
delta, confidence, score_weights = (
    self._compute_gaussian_score_shift(
        mu=mu,
        sigma=sigma,
        alpha_effective=alpha_effective,
        patch_num=patch_num,
        device=x_seq.device,
    )
)

res_proj = self.patch_residual(
    x_seq=x_seq,
    delta=delta,
    confidence=confidence,
)

rendered_event = (
    rendered_event
    + self.gs_residual_weight * res_proj
)
```

### 兼容旧诊断接口

为了避免现有测试脚本报错，设置：

```python
self.last_gate_direction = (
    delta / (max_shift + eps)
).detach()

self.last_gate_strength = confidence.detach()
self.last_gate_scale = torch.ones_like(confidence)

self.last_score_shift = delta.detach()
self.last_score_confidence = confidence.detach()
self.last_score_weights = score_weights.detach()
```

原来的三分类路由概率可以构造为诊断值：

```python
neutral = 1.0 - confidence
forward = (
    confidence
    * torch.relu(
        self.last_gate_direction
    )
)
reverse = (
    confidence
    * torch.relu(
        -self.last_gate_direction
    )
)

normalizer = (
    neutral + forward + reverse + eps
)

self.last_gate_route_probs = torch.cat(
    [
        neutral / normalizer,
        forward / normalizer,
        reverse / normalizer,
    ],
    dim=-1,
)
```

这些概率只用于兼容测试和可视化，不参与主要计算。

# 五、实现顺序

## 第一步：重构 `patch_residual.py`

先独立实现 `GaussianJetProjection`，不接入完整模型。

使用随机输入验证：

```python
x_seq.shape = [B, C, seq_len]
delta.shape = [B*C, patch_num, 1]
confidence.shape = [B*C, patch_num, 1]
```

输出必须为：

```python
[B*C, patch_num, d_model]
```

检查：

- forward 无维度错误；
- backward 无梯度错误；
- 不产生 `[B*C, P, D, L]` 张量；
- `gaussian_up` 能获得非零梯度；
- `g_mu`、`g_sigma` 能获得梯度。

------

## 第二步：在编码器中加入解析位移

实现 `_compute_gaussian_score_shift()`。

使用人工高斯参数测试符号方向：

- 高斯中心位于查询点右侧时，`delta` 应为正；
- 高斯中心位于查询点左侧时，`delta` 应为负；
- 高斯中心与查询点重合时，`delta` 应接近零；
- `delta` 的绝对值不得超过 `max_shift_samples/(patch_len-1)`。

------

## 第三步：替换两阶段投影

在 `residual_mode="gaussian_jet"` 时：

- 不调用 `get_base_projection()`；
- 不调用 `AdaptiveResidualRouter`；
- 不生成 `M_modulator`；
- 不生成 `W_dynamic`；
- 只执行一次 `base_projection`；
- 只生成 `[B*C, P, K]` 的 Gaussian Jet 响应。

------

## 第四步：保持 legacy 模式

确认：

```python
residual_mode="legacy_dynamic_shell"
```

仍然能够复现旧实现。

不要为了新模块直接删除旧动态高斯壳，否则无法进行论文消融和结果对比。

------

## 第五步：性能验证

在同一个 batch、同一个配置和同一个 GPU 上记录：

```text
训练单 step 时间
峰值显存
参数量
FLOPs 或 MACs
```

对比：

```text
普通线性残差
旧动态高斯壳
Gaussian Jet
```

目标门槛：

```text
Gaussian Jet 相对普通线性残差：
训练时间不超过 1.30 倍
峰值显存不超过 1.20 倍
```

# 六、必须增加的正确性测试

## 6.1 零初始化退化测试

```python
gaussian_up.weight == 0
```

应满足：

\text{base_projection}(x)

允许仅有浮点误差。

测试：

```python
assert torch.allclose(
    output,
    base_output,
    atol=1e-6,
    rtol=1e-5,
)
```

------

## 6.2 零位移测试

当：

```python
delta = 0
```

时：

```python
q_jet == q0
```

------

## 6.3 常量输入导数响应测试

对于常量 patch：

```python
patches = torch.ones(...)
```

一阶高斯导数响应：

```python
q1
```

应接近零。

如果不接近零，检查：

```python
psi = psi - psi.mean(dim=-1, keepdim=True)
```

是否正确执行。

------

## 6.4 小平移近似测试

构造一个平滑 patch (x)，比较：

1. 精确计算平移后的高斯响应；
2. 一阶 Jet 近似：

[
q_0+\delta q_1
]

对于较小 (\delta)，误差应随 (\delta^2) 缩小。

建议测试：

```text
delta = 0.25 sample
delta = 0.50 sample
delta = 1.00 sample
```

------

## 6.5 位移符号测试

构造单峰输入：

- 峰值向右移动时；
- 峰值向左移动时。

验证 Gaussian score 的位移方向与设定一致。

这是最容易出现符号错误的地方，必须单独测试。

------

## 6.6 梯度测试

完成一次：

```python
loss = output.square().mean()
loss.backward()
```

确认以下参数梯度有效且有限：

```python

gaussian_up.weight.grad

g_sigma.grad
```

检查：

```python

```

# 七、实现注意事项

## 7.1 控制 sigma 下界

必须使用：

```python
sigma = F.softplus(self.g_sigma) + sigma_min
```

建议：

```python
sigma_min = 0.03
```

避免高斯尺度过小导致：

```text
1 / sigma²
```

爆炸。

------

## 7.2 保持 dtype 一致

构建时间坐标时必须使用：

```python
dtype=patches.dtype
device=patches.device
```

避免 AMP 或混合精度下发生隐式 FP32 转换。

------

## 7.3 不缓存带梯度的基底

不要将当前 forward 中计算出的 `phi` 和 `psi` 直接缓存为长期成员变量，否则可能保留计算图。

诊断时只能保存：

```python
self.last_phi = phi.detach()
self.last_psi = psi.detach()
```

------

## 7.4 不使用 in-place 操作修改 delta

不要对：

```python
delta
confidence
score_weights
```

执行可能破坏 autograd 的原地修改。

------

## 7.5 统一位移单位

必须明确区分：

```text
sample unit
normalized time unit
```

外部配置使用：

```python
jet_max_shift_samples
```

模块内部统一转换为：

```python
jet_max_shift_samples / (patch_len - 1)
```

论文和代码中都应遵循同一约定。

------

# 八、最终目标结构

修改完成后的模型逻辑应为：

```text
Normalized input
        │
        ├─────────────────────────────────────┐
        │                                     │
        ▼                                     ▼
Explicit Gaussian path                Implicit linear path
Temporal Gaussian Splatting           Patch extraction
        │                                     │
mu, sigma, alpha                              ├─ Base Linear
        │                                     │
Analytic Gaussian score                       ├─ Gaussian basis φ
        │                                     ├─ Gaussian derivative ψ
delta + confidence ─────────────────────────► ├─ q0 + delta · q1
                                              ├─ Low-rank projection
                                              │
                                              ▼
                                   Base + Gaussian Jet adapter
        │                                     │
        └────────────────── Fusion ───────────┘
                              │
                              ▼
                         Forecast head
```

新结构应满足：

- 显式通路仍然是 Gaussian Splatting；
- 线性通路仍然具有隐式高斯参数化；
- 显式高斯通过解析位移指导隐式高斯；
- 局部平移通过 Gaussian derivative 进行一阶校正；
- 不再实例化完整动态线性权重；
- 不再执行第一次基础投影；
- 普通线性主干始终保留；
- 新模块初始化时能够退化为普通 Linear。

------

# 九、实现完成后的验收标准

Antigravity 完成修改后，至少需要满足：

1. `gaussian_jet` 模式可正常训练和推理；
2. 旧 `legacy_dynamic_shell` 模式仍可运行；
3. 输出维度与修改前完全一致；
4. 不存在 `[B*C, P, D, L]` 动态张量；
5. Gaussian Jet 残差分支只执行一次普通 Linear；
6. 初始输出与普通线性投影基本一致；
7. 位移方向通过人工单峰测试；
8. 小平移近似误差表现为近似二阶下降；
9. AMP 下不存在 NaN 或 Inf；
10. 保存 Gaussian score、位移、置信度、Jet/Base 范数等诊断指标；
11. 训练时间和峰值显存显著低于旧动态高斯壳；
12. 配置文件支持 `linear`、`legacy_dynamic_shell` 和 `gaussian_jet` 三种消融模式。
